# PortafolioTalleres
El proyecto consiste en desarrollar una pequeña plataforma web estática destinada a presentar una colección de infografías desarrolladas en el contexto universitario.  La plataforma permitirá al usuario explorar las infografías disponibles y visualizar cada documento directamente dentro de la página, evitando depender del visor PDF predeterminado del navegador.  Los documentos PDF serán renderizados mediante PDF.js, permitiendo controlar completamente la interfaz de visualización y proporcionar una experiencia similar a la visualización de una imagen, pero conservando las ventajas del formato PDF, especialmente su capacidad de ampliación.  El proyecto prioriza la simplicidad, el bajo costo de mantenimiento y la facilidad para incorporar nuevas infografías.
